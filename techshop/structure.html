تشريح مجلدات لارافيل 12 وكيف تبدو من الداخل

تعرف على دورك اليومي كمهندس باك إند في كل مجلد، كيف يبدو شكله وهيكله من الداخل، كود PHP حقيقي من واقع مشروع TechShop، وأين تضع كل سطر كود باحترافية.

/app 80% من وقتك اليومي (Models & Services & Controllers)
/routes ربط نقاط نهاية الـ REST API والـ WebSockets
/database Migrations للجداول والـ Seeders لملء البيانات
/storage ملفات الـ Uploads وسجلات تتبع الأخطاء Logs

انقر على أي مجلد أدناه لاستعراض هيكله الداخلي، الكود الفعلي المكتوب جواه، ونصائح عملية لشغلك اليومي:

جدول المهام اليومية

جدول الشغل اليومي للمطور مع هذه المجلدات

ملخص سريع يوضح معدل تعديلك على كل مجلد وما تفعله بداخله أثناء بناء الميزات الجديدة:

المجلد معدل عملك عليه ماذا تفعل بداخله؟ (شغلك العملي) أهم ملف أو مجلد بداخله
/app 🔥 دائماً (80% من وقتك) كتابة الـ Models، الـ Services، تقسيم الطلبات، بوابات الدفع، والتحقق FormRequests. app/Services/ & app/Models/
/routes 🔥 يومياً إضافة مسارات Endpoints جديدة للـ API ولوحة الويب وقنوات Reverb. routes/api.php
/database ⚡ مع كل ميزة جديدة إنشاء Migrations للجداول الجديدة وإضافة أعمدة وفهارس وحقن بيانات الـ Seeders. database/migrations/
/config ⚙️ أحياناً ضبط إعدادات بوابات الدفع Kashier، مفاتيح Firebase FCM، وإعدادات Reverb. config/services.php
/resources 🎨 أحياناً تعديل قوالب فواتير الـ PDF وقوالب رسائل البريد وملفات الترجمة (ar/en). resources/views/
/storage 🔍 عند فحص الأخطاء قراءة سجلات الأخطاء laravel.log وفحص الصور والملفات المرفوعة. storage/logs/laravel.log
/public 🌐 نادراً ربط مجلد التخزين العام عبر php artisan storage:link ووضع الأيقونات العامة. public/index.php
/bootstrap 🚀 نادراً جداً تسجيل الميدلويرز العامة واستثناءات الـ CSRF والـ Exception Handlers في app.php. bootstrap/app.php
القرار السريع

أين أضع كودي؟ (Cheat Sheet)

دليل إرشادي سريع لحسم مكان وضع أي كود جديد دون حيرة:

علاقات الجداول وحقول قاعدة البيانات:
← داخل app/Models/YourModel.php
حسابات تقسيم الطلبات والمدفوعات والمفاوضات:
← داخل app/Services/YourService.php
فحص صحة مدخلات الـ Request (Required, Email..):
← داخل app/Http/Requests/YourRequest.php
تنسيق الـ JSON المرجع لتطبيق الموبايل:
← داخل app/Http/Resources/YourResource.php
المهام المجدولة اليومية وفحص الاشتراكات:
← داخل app/Console/Commands/ و routes/console.php
الأحداث اللحظية وتتبع المناديب بالـ GPS:
← داخل app/Events/ مع تفعيل ShouldBroadcast
