دليل بدء وتشغيل TechShop من الصفر

خطوات واضحة ومباشرة لتجهيز بيئة العمل، ترحيل قاعدة البيانات، ربط التخزين، تشغيل الـ WebSockets والـ Queues، واختبار الـ APIs عبر Postman.

المتطلبات الأساسية

1. متطلبات بيئة التشغيل (Prerequisites)

تأكد من تثبيت الأدوات التالية على جهازك أو السيرفر قبل البدء:

PHP 8.2+ مع إضافات: bcmath, ctype, curl, gd, pdo_mysql, mbstring
MySQL 8.0+ أو MariaDB 10.5+ لدعم الـ GeoJSON والـ Spatial indexes
Node.js 18+ مع NPM لتجميع الأصول عبر Vite
Composer 2+ مدير حزم PHP
أوامر التثبيت

2. خطوات التثبيت والتشغيل خطوة بخطوة

  • الخطوة 1: الدخول للمشروع وتثبيت الحزم

    قم بالدخول إلى مجلد الباك إند وتثبيت حزم الـ PHP والـ JavaScript:

    # الدخول للمجلد
    cd C:\Users\AL.LEWAA\OneDrive\Documents\backend\zew

    # تثبيت حزم Composer
    composer install

    # تثبيت حزم NPM وبناء أصول الواجهة
    npm install && npm run build
  • الخطوة 2: إنشاء ملف .env ومفتاح التشفير

    قم بنسخ ملف الإعدادات وتوليد مفتاح الأمان للتطبيق:

    cp .env.example .env
    php artisan key:generate
  • الخطوة 3: ضبط بيانات قاعدة البيانات والـ Services في ملف .env

    افتح ملف .env وعدل المتغيرات التالية بما يناسب بيئتك:

    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=backendpro_zew
    DB_USERNAME=root
    DB_PASSWORD=

    # إعدادات البث اللحظي Reverb
    BROADCAST_CONNECTION=reverb
    REVERB_APP_ID=techshop-app
    REVERB_APP_KEY=techshop-key
    REVERB_APP_SECRET=techshop-secret
    REVERB_HOST="localhost"
    REVERB_PORT=8080
    REVERB_SCHEME=http

    # إعدادات طوابير المهام
    QUEUE_CONNECTION=database
  • الخطوة 4: ترحيل قاعدة البيانات وتشغيل الـ Seeders أو استيراد SQL

    يمكنك إما تشغيل الترحيل التلقائي مع الـ Seeders أو استيراد ملف الداتا الجاهز مباشرة:

    # الخيار 1: ترحيل جديد مع تشغيل الـ Seeders
    php artisan migrate:fresh --seed

    # الخيار 2: استيراد ملف SQL الموجود في المشروع مباشرة
    mysql -u root -p backendpro_zew < backendpro_zew.sql
  • الخطوة 5: ربط مجلد التخزين العام (Storage Symlink)

    ضروري جداً لتظهر صور المنتجات والمتاجر والرخص وإثباتات التسليم في التطبيق:

    php artisan storage:link
  • الخطوة 6: تشغيل الخدمات الأساسية (السيرفر، الريال تايم، والـ Queues)

    قم بفتح نوافذ Terminal منفصلة لتشغيل الخدمات المتزامنة:

    # نافذة 1: تشغيل خادم الويب والـ API
    php artisan serve

    # نافذة 2: تشغيل خادم الـ WebSockets اللحظي (Laravel Reverb)
    php artisan reverb:start

    # نافذة 3: تشغيل معالج الطوابير (Queue Worker للإشعارات والإيميلات)
    php artisan queue:work

    # نافذة 4 (أثناء التطوير): تشغيل المهام المجدولة دورياً
    php artisan schedule:work
حسابات الاختبار الافتراضية

3. بيانات الدخول الافتراضية (Default Credentials)

الحسابات المُنشأة تلقائياً بواسطة UserSeeder لتجربة كافة الأدوار فوراً:

Super Admin: admin@admin.com
كلمة المرور: 12345678 | صلاحية كاملة
Vendor (تاجر): vendor@vendor.com
كلمة المرور: 12345678 | متجر وفروع وستوك
Customer (عميل): user@user.com
كلمة المرور: 12345678 | طلبات ومحفظة وباكدج
اختبار الـ API والـ Collections

4. أدوات الاختبار ومجموعات Postman / Apidog

ملفات Postman & Apidog الجاهزة في المشروع

  • Multi-Vendor E-Commerce API.postman_collection.json

    مجموعة بوستمان متكاملة تشمل كافة نقاط نهاية الـ API (Auth, Vendors, Products, Cart, Orders, Packages, Wallet).

  • postman_environment.json

    متغيرات البيئة للـ Base URL والـ Bearer Token.

  • zew-updated .apidog.json

    ملف توثيق واختبار شامل جاهز للاستيراد في برنامج Apidog.

تشغيل الاختبارات الآلية (Automated PHPUnit Tests)

يمكنك تشغيل حزمة الاختبارات الآلية للتأكد من سلامة كافة الـ Endpoints وسير العمليات:

# تشغيل كافة الاختبارات عبر PHPUnit
php artisan test

# أو عبر سكريبت PowerShell المرفق:
.\run-automated-tests.ps1

كل شيء جاهز للتشغيل والتطوير!
